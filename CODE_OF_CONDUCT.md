# Code of conduct

flowverse is part of humanize, and everyone taking part in it — in issues, pull requests,
reviews and anywhere else the project meets — follows
[humanize's code of conduct](https://github.com/humanfia/humanize/blob/main/CODE_OF_CONDUCT.md),
the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report unacceptable behavior as that code of conduct says. Its maintainers enforce it here too.
