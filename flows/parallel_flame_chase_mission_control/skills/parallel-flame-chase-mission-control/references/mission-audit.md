# Mission Control audit decisions

The initial policy has already decided that this event merits an audit and selected its scope. Do
not reopen that policy choice. Decide each exact target once using only the current revision packet
and concrete workspace evidence.

- `continue`: retain the mission when it remains the best information-bearing work;
- `redirect`: reject it and supply a materially different, falsifiable replacement;
- `accept`: only for a validated `deliverable_ready` outcome.

Accepting Lane 2 or 3 requires an integration directive for Lane 1 and a next mission for the
research lane. Lane 1 never enqueues to itself. Bind the answer to the exact audit ID and revision;
newer evidence invalidates stale decisions.
