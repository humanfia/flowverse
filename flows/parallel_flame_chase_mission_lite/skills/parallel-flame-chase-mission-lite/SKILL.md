# Mission Lite Parallel Flame Chase

Treat the runtime prompt as authoritative for role, objective, workspace ownership, mission
identity, and audit revision. Read [collaboration.md](references/collaboration.md) before acting.

- Initial orchestrateor: create three materially different, falsifiable candidate-producing
  missions. Lane 1 owns the original source; Lanes 2 and 3 own private snapshots.
- Lane actor: execute the current mission and return an evidence-backed `LaneReport`.
- Audit orchestrateor: read [mission-audit.md](references/mission-audit.md) and decide exactly the
  named targets.

A terminal outcome normally pauses only its lane. A locally evaluated candidate that strictly
refreshes the primary shared best escalates the audit to all three lanes. Do not describe an
ordinary deliverable, a tied score, an alternate metric leader, or an unvalidated estimate as a
shared-best refresh.

This flow coordinates local work only and grants no remote submission, deployment, release,
purchase, or messaging authority.
