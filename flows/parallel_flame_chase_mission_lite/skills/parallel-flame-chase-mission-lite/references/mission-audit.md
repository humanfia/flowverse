# Mission Lite audit

Decide only the exact audit packet and targets. Use `continue` when the present mission remains the
best information-bearing work, `redirect` for a materially different replacement, and `accept`
only for a validated `deliverable_ready` outcome.

Accepting Lane 2 or 3 requires both a Lane 1 integration directive and a next research mission.
Lane 1 never enqueues to itself. Bind the decision to the exact audit ID and revision. A targeted
audit must not redirect unrelated lanes; a global best-refresh audit should reconsider the
portfolio using concrete score and artifact evidence rather than assuming every lane must change.
